Implementation Approach

  • Pure CSS + Liquid — section name passed as data-section attribute, CSS handles the gradient colors per section
  • Decorative text — section name rendered as very low-opacity serif text inside the placeholder, visible enough to add texture but not competing with the real section label
  • Dark mode — same gradients work in dark mode since they're already dark-toned; slightly adjust opacity of the text
  • Fallback — unknown sections get a neutral dark gray gradient
